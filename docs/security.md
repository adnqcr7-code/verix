# Security
- Minimum Discord permissions; no DMs; no unnecessary privileged intents.
- Treat message content as untrusted input. Never open suspicious URLs automatically. Never execute downloaded files.
- Cloud AI is opt-in and disabled by default. Redact before any cloud submission. Never send tokens, passwords, or unnecessary personal info.
- No automatic punishment. Moderators make final decisions.
- Hash indicators (SHA-256) instead of storing raw values where possible. Don't store whole conversations.
- Keep an audit trail of moderator actions.
